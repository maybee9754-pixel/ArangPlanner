# ArangPlanner v0.9.0-demo · UI 상호작용 및 일치도

## 변경 사항

1. **장비 슬롯 선택/마우스오버 발광 강화:** 슬롯 위에서 보라색 외곽선과 부드러운 하이라이트
2. **게임 아이템 툴팁 방향 조정:** 왼쪽 슬롯은 오른쪽, 오른쪽 슬롯은 왼쪽, 장신구는 슬롯 위로 표시하도록 변경. 화면 밖으로 나가지 않도록 클램프
3. **캐릭터 및 마법진 정렬:** 중앙 마법진과 PlayerModel 중심을 소폭 아래로 조정
4. **보스 목록 펼침 통일:** 첫 보스 네크잘리만 펼친 예시 목록, 나머지 보스는 축약 표시. 웹 스튜디오에서 이미 사용하던 시각적 구조와 통일

## 설치 및 주의
- GitHub Release 태그: `v0.9.0-demo`
- 다운로드 파일: `ArangPlanner_v0.9.0-demo.zip` (빌드/배포 성공 후 제공)
- WoW 종료 후 업데이트 설치하고 다시 실행한 뒤 `/arang` 입력
- 웹 스튜디오: https://maybee9754-pixel.github.io/ArangPlanner/
- 기존 GearPlanner 데이터는 변경하지 않음
- **보스 획득 수치 및 능력치 비교는 여전히 예시 데이터**
- 실제 WoW 클라이언트에서 렌더링 및 툴팁 위치는 사용자의 테스트로 확인해야 함
