# 개발 상태

## 아랑플래너 UI

확정된 시안 디자인은 다크 판타지 UI, 얇은 테두리, 캐릭터 중심의 3단 레이아웃입니다.

- 왼쪽: 파밍 현황 / 능력치 비교 / 미획득 아이템
- 중앙: 실제 착용 장비 / 캐릭터 모델 / 장신구
- 오른쪽: 보스 / 전리품 목록

## 기존 데모

v0.4.0-demo는 실제 WoW에서 동작 확인 중인 UI 시험판으로, 디자인 목표와 차이가 있습니다. 실제 스캔 로직이 포함된 정식 애드온으로 취급하지 않습니다.

## 다음 개발 작업

1. 확정 시안의 UI 텍스처 및 배치 구현
2. WoW 환경에서 기본 기능과 UI 오류 검증
3. Windows 업데이트 매니저 복구 및 ZIP 설치 안정화
4. GitHub Release를 통한 테스트 배포
